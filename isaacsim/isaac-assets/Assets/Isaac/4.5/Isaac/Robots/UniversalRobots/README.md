# README.md

The Universal Robots USD assets were generated using the URDF Importer (0.3.0) in Isaac Sim 2022.1.1.

The URDFs were generated from the repo: https://github.com/UniversalRobots/Universal_Robots_ROS2_Description

- Ubuntu 20.04
- ROS2 foxy
- Modify the [/test/test_ur_urd_xacro.py](https://github.com/UniversalRobots/Universal_Robots_ROS2_Description/blob/ros2/test/test_ur_urdf_xacro.py) file to output a static instead of temp file
